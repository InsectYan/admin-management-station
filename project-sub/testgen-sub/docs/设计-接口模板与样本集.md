# 设计 · 接口模板与多样本执行

## 1. 目标

- **配置管理 → 接口模板**：维护可复用 HTTP 请求模板（method、headers、body、inject_schema）。
- **用例配置（TPL-DET）**：可选「关联接口模板」，为每个 inject 字段选手动值或样本集。
- **样本集三分型**：`http`（完整 HTTP 样本）、`text`（单行文本，供 inject 引用）、`inject`（多字段组合 JSON）。
- **执行**：选用样本集时，按样本条数展开多次 sub_run（TS-01-DET）。

## 2. 数据库

| 表/列 | 变更 |
|-------|------|
| `ft_api_template` | 新建，见 `migrations/021_*.sql` |
| `ft_sample_set.set_type` | `http` \| `text` \| `inject` |
| `ft_sample_set.api_template_id` | inject 型可选关联模板 |
| `ft_run_config.use_api_template` | 是否走模板渲染 |
| `ft_run_config.api_template_id` | 模板 ID |
| `ft_run_config.inject_bindings` | `{fieldKey:{mode,value?,sample_set_id?,field_key?}}` |

## 5. 执行引擎

`backend/app/lib/apiTemplateRender.js`：

- `renderApiRequest(template, injectValues)` — 单请求渲染
- `expandApiTemplateRuns(template, bindings, sampleRows)` — 样本矩阵展开

`ts01DetEngine` 在 `use_api_template=true` 时调用上述逻辑，多样本 → 多 `sub_index`。

## 6. Agent · 接口模板自动生成

| 组件 | 说明 |
|------|------|
| `api-template-skill`（Loop） | 文档 → analyze/generate/review 三步生成 `ft_api_template` 草案 |
| `api_template_generation_jobs` | 生成任务表，用户确认后写入 `ft_api_template` |

**前端路由**

| 路径 | 页面 |
|------|------|
| `/config/api-templates/gen` | 自动化配置（上传文档 + 备注） |
| `/config/api-template-jobs/:id` | 生成进度 + 确认导入 |

**API**

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/api-template-jobs` | 创建并启动生成任务 |
| GET | `/api/api-template-jobs/:id` | 查询进度 |
| POST | `/api/api-template-jobs/:id/confirm-import` | 确认导入 `ft_api_template` |

## 8. 示例：教练 Turn Submit

种子模板 `coach-turn-submit`：`POST /turns/submit`，inject 字段 `coach_id`、`message`、`session_id`。
