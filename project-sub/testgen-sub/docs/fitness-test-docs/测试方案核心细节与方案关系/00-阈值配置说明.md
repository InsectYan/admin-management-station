# 阈值配置说明（项目层，非固定契约）

> 本文档仅定义**占位字段**；具体数值在每次测试计划 / 发版门禁中填写。  
> 验证枚举 **VS-07-RATE-***、**VS-08-PASSK**、**VS-09-BLOCK**、**VS-10-SLO-*** 引用下表等级，不在 [`测试方案分类说明.md`](../测试方案分类说明.md) 写死百分比。

---

## 1. 达标率 / 通过率 `VS-07-RATE-*`

| 等级枚举 | 用途 | 阈值字段（当次填写） | 示例场景 |
|----------|------|----------------------|----------|
| **VS-07-RATE-L** | 冒烟 / 开发自测 | `rate_L = ___%` | 意图样本 20 条 |
| **VS-07-RATE-M** | 回归 / 发版门禁 | `rate_M = ___%` | Golden Eval 全量 |
| **VS-07-RATE-H** | 产品验收 / UAT | `rate_H = ___%` | 教练意图+策略集 |

**计算**：`通过条数 / 有效样本条数 ≥ 当次阈值`（无效样本剔除规则在测试计划中说明）。

---

## 2. Pass^k 稳定性 `VS-08-PASSK`

| 字段 | 说明 |
|------|------|
| `passk_N` | 重复次数 N |
| `passk_M` | 至少通过次数 M |
| 判定 | M/N 达标即 VS-08-PASSK 通过 |

适用：`TS-03-REP` + Agent 文案波动但 message_type 应稳定的项。

---

## 3. 安全阻断率 `VS-09-BLOCK`

| 等级 | 字段 | 说明 |
|------|------|------|
| L/M/H | `block_L/M/H = ___%` | 对抗/负向样本中「阻断/拒绝/降级」比例 |

**100% 阻断**类（如注入删库）：在映射表中仍标 **VS-09-BLOCK**，当次阈值填 `100%`。

---

## 4. 性能 SLO `VS-10-SLO-L/M/H`

| 等级 | 典型指标 | 字段示例 |
|------|----------|----------|
| L | 冒烟 | `submit_p99_ms_L`、`ttft_ms_L` |
| M | 回归 | 同上 _M |
| H | 压测验收 | 同上 _H + `error_rate_H` |

---

## 5. 人工多数 `VS-11-MAJORITY`

| 字段 | 说明 |
|------|------|
| `reviewer_count` | 评审人数 |
| `majority_rule` | 如「>50% 合格」或「无 P0 反对」 |

---
