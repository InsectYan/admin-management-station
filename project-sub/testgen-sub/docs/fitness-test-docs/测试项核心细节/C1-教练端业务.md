# C1 · 教练端业务 — 核心细节表

> **PRD 主线**：用户输入→识别端/身份→意图→会员对象→权限→上下文→skill→策略→安全审查→载荷→确认→写库→日志

## C1.1 入口与会员上下文（PRD §4.1）

| 测试项 ID | 子类 | 测试核心细节 | 预期 / 观测点 | 优先级 | 自动化 |
|-----------|------|--------------|---------------|--------|--------|
| C1-ENTRY-001 | 通用主对话 | 通用入口问健身知识 | text 问答，无 plan_form | P0 | E2E coach |
| C1-ENTRY-002 | 通用主对话 | 「给张三做计划」未进会员窗 | 先识别/切换，不直接 plan_form | P0 | 人工/待 E2E |
| C1-ENTRY-003 | 会员窗口 | 已绑定会员生成计划 | 结合档案上下文 | P0 | E2E chain |
| C1-ENTRY-004 | 上下文隔离 | 会员 A 窗口 | 不得引用会员 B 档案 | P0 | 人工 |
| C1-ENTRY-005 | 同名消歧 | 两个「李四」 | message_type=disambiguation + 候选列表 | P0 | 待建 |
| C1-ENTRY-006 | 切换会员 | 跨会员请求 | member_switch_data，确认前无 plan_form | P0 | 待建 |
| C1-ENTRY-007 | 无权限会员 | 读取/生成 | 403 或明确拒绝 | P0 | 待建 |
