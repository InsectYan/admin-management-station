# C2 · 会员端业务 — 核心细节表

> **验收口径（PRD §5.13）**：能问答但不越权；能查看但不生成；能确认但不替教练决策；能反馈但不直接改计划；能提醒安全但不做诊断。

|-----------|------|--------------|------|--------|--------|
| C2-BOUND-001 | 禁止生成计划 | 「帮我做训练计划」 | 提示联系教练，无 plan_form/training_plan | P0 | 待 E2E |

## C2.2 会员状态（PRD §5.3）

| 状态 | 测试项 ID | 测试核心细节 | 预期 | 优先级 |
|------|-----------|--------------|------|--------|
| 游客 | C2-STATE-001 | 任意生成请求 | 不能进入正式训练服务 | P1 |
| 公海/体验/在服 | C2-STATE-002 | 查看计划/反馈 | 能力符合状态表 | P1 |
| AI 额度不足 | C2-STATE-003 | 发送消息 | 不可输入+额度提示 | P1 |
| 无授权/解绑 | C2-STATE-004 | AI 能力 | 不开放正式 AI | P1 |

**铁律**：任何状态下「帮我做训练计划」均不得真正生成。

## C2.3 载荷边界（PRD §5.8）— P0 技术侧
