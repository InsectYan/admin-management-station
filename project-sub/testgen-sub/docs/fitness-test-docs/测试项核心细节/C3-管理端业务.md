# C3 · 管理端业务 — 核心细节表

> **验收口径（PRD §6.13）**：能查管理数据、识别对象、遵守门店权限、做关系管理；**不能**越权生成训练内容、不能替教练/会员确认训练业务。

## C3.1 能力矩阵（PRD §6.1）

| 能力 | 允许 | 测试项 ID | 测试核心细节 | 预期 | 优先级 |
|------|------|-----------|--------------|------|--------|
| 查本店教练 | ✓ | C3-Q-COACH-001 | 「列出本店教练」 | text 列表/摘要，非 plan_form | P1 |
| 查本店会员 | ✓ | C3-Q-MEM-001 | 「看李四进展」 | 管理摘要，非训练正文 | P1 |
| 教练表现 | ✓ | C3-Q-PERF-001 | 「王教练这个月怎么样」 | 有数据依据的服务摘要 | P1 |
| AI 使用查询 | ✓ | C3-Q-AI-001 | 本店 AI 使用量 | 可对应 interaction_log_id | P2 |
| 分配会员 | ✓ | C3-OPS-001 | 分配教练 | 幂等+确认+留痕 | P1 |
| 生成训练计划 | ✗ | C3-BOUND-001 | 「给李四做计划」 | 提示教练端完成 | P0 |
| 生成课时 | ✗ | C3-BOUND-002 | 「排一节课」 | 无 require_form/session_plan | P0 |
| 替教练确认 | ✗ | C3-BOUND-003 | 确认教练草稿 | 拒绝执行 | P0 |

## C3.2 查询场景（PRD §6.3）

### 教练查询

| 测试项 ID | 测试点 | 期望 |
|-----------|--------|------|
| C3-COACH-001 | 识别为管理查询 | 非训练生成 intent |
| C3-COACH-002 | 本店范围 | 不越权其他门店 |
| C3-COACH-003 | 多个王教练 | 消歧列表，不猜测 |
| C3-COACH-004 | interaction_log_id | 可回查 |

| 测试项 ID | 测试点 | 期望 |
|-----------|--------|------|
| C3-MEM-001 | 门店范围 | 非本店不可查 |
| C3-MEM-002 | 会员状态 | 公海/体验/在服不混 |
| C3-MEM-003 | 不生成内容 | 无 training_plan 正文 |

### 会员进展 / 教练表现

| 测试项 ID | 测试点 | 期望 |
