# project_request_header · 项目默认请求头

| 字段 | 说明 |
|------|------|
| project_code | 所属项目 |
| header_key | 请求头名（如 `Authorization`、`X-Internal-Service-Key`） |
| header_value | 请求头值 |
| sort_order | 展示/保存顺序 |

用途：项目管理 →「请求头」Tab。HTTP 执行合并顺序：

```text
{ ...环境 auth_configured.global_headers, ...项目请求头, ...用例 config_json.headers }
```

用例配置页 Headers 权重最高。执行前 **不**将请求头缺失作为 CONFIG_AUTOFILL 阻断项。
