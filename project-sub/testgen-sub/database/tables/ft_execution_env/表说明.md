# ft_execution_env · 执行环境（按项目）

| 字段 | 说明 |
|------|------|
| project_code | 所属项目（ENV-01；与 `test_project.project_code` 对齐，软关联） |
| name | 环境名；同一项目内唯一 |
| config_env_id | 配置环境标识（如 LOCAL_DOCKER / LOCAL_HOST） |
| bff_*_url / agent_chat_url | 各 BFF / Agent 基址 |
| cli_workspace_root | CLI 工作区根路径（容器内常为 `/fitness-agent`） |
| auth_configured | 鉴权与连接 JSON（含 `database_url` 等） |
| is_default | 项目内默认环境；每个 `project_code` 至多一条为 true |

用途：Launch / 批量执行解析目标主机与鉴权；**禁止跨项目落到 fitness-agent 默认环境**。

## 变更范围

- **改表，不建新表**：仅 `ft_execution_env` 增加 `project_code` 与项目级唯一索引。
- Agent 自动补齐**不新增表**；元数据写在 `ft_run_config.config_json`。

## 相关脚本

| 文件 | 作用 |
|------|------|
| `init.sql` / `data.json` | DDL 真源 + fitness-agent 种子 |
| `007` / `008` | 早期种子 INSERT（带 `project_code`） |
| `021` / `022` | CLI 工作区、`database_url`（按项目 UPDATE） |
| `038_ft_execution_env_project_code.sql` | 补列、回填、索引、补齐种子（幂等） |

部署：`cd backend && npm run db:sync`（或 `npm run db` 含 seed）。
