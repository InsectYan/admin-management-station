# ft_api_template · HTTP 接口请求模板

| 字段 | 说明 |
|------|------|
| template_code | 模板编码（唯一） |
| name | 显示名称 |
| http_method / url_path | 请求方法与路径 |
| headers_json / query_json / body_template | 请求模板 JSON |
| inject_schema | 可注入字段 `[{key,label,location,json_path}]` |
| is_active | 软删除标记 |

用途：配置管理 · 接口模板；用例通过 `ft_run_config.use_api_template` 引用并配置 `inject_bindings`。
