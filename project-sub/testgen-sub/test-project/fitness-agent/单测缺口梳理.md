P0 落地项已通过 [sync-automation-status.mjs](./scripts/sync-automation-status.mjs) 回写 `test_item_detail` 的：

- `automation_entry_id` → `AUTO_S01` ~ `AUTO_S06` 等
- `automation_command` → `npm run test:stations -- <filter>`
- `code_reference` → 测试文件路径
