# fitness-agent · 运行命令与前置

> 工作目录默认为 **`fitness-agent/server`**（E2E / 站级均在此执行）。  
> 与 fitness-agent 仓库内 [server/tests/README.md](../../../../../../fitness-agent/server/tests/README.md) 保持一致。

---

## 环境准备

| 场景 | 命令 | 说明 |
|------|------|------|
| 启动全栈 | `fitness local` | Postgres `:5433` + Server `:3001` + 前端 `:5173` |
| 清运行时 | `fitness local:clean` | 保留种子人物，清对话/计划/队列 |
| 重建库 | `fitness local:reset` | 删 volume + 重跑 init |
| Server 依赖 | `cd server && npm install` | 首次或依赖变更后 |

站级测试需 `server/.env` 中 `DATABASE_URL` 指向本地 Postgres（`fitness local` 会自动配置）。

## 站级：一起测

```bash
cd fitness-agent/server
npm run test:stations
```

执行顺序：s01 前端 → s02~s06 全部 `*.test.ts`（含 s04 全部 suite）。

---

## 站级：单一测（filter）

```bash
npm run test:stations -- <filter>
```

### 按站

| filter | 范围 |
|--------|------|
| `s01` / `frontend` | s01-frontend + agent-sse |
| `s02` | 门禁 4 个 test 文件 |
| `s03` | store + lifecycle + retry |
| `s04` | 全部 5 个 suite |
| `s05` | Pi 契约 + draft merge |
| `s06` | journey + sse-frame |

### 按文件 / suite（常用）

| filter | 测试文件 |
|--------|----------|
| `db-circuit` | s02 DB 熔断 |
| `turn-queue-policy` | s02 队列策略 |
| `s02-key` | Internal API Key |
| `turn-submit-guard` | s02 基础门禁 |
| `turn-job-lifecycle` | s03 claim/stale |
| `s03-retry` | s03 重试纯函数（**无 DB**） |
| `s04-bff` / `s04-macro` / `s04-session` | s04 子 suite |
| `s04-outbox` / `s04-portal` | outbox / 载荷契约（**无 DB**） |
| `sse-frame` | SSE 帧（**无 DB**） |
| `agent-sse` | 前端 queue hint（**无 DB**） |

### 直接跑单文件（不经 runner）

```bash
node node_modules/tsx/dist/cli.mjs src/stations/s02-gate/tests/db-circuit.test.ts
node node_modules/tsx/dist/cli.mjs src/stations/s03-queue/tests/turn-job-retry.test.ts
cd ../frontend && node ../server/node_modules/tsx/dist/cli.mjs tests/agent-sse.unit.ts
```

### DB 依赖速查

| 需要 Postgres | 不需要 Postgres |
|---------------|-----------------|
| turn-submit-guard, turn-queue-policy, turn-job-*（除 retry）, s04 bff/macro/session, turn-journey | db-circuit, s02-key, s03-retry, s04-outbox/portal, s05-*, sse-frame, agent-sse |

## E2E：一起测 / 单一 suite

**前置**：Docker Server `:3001` 运行中 + `server/.env` 含 LLM Key。

```bash
cd fitness-agent/server
npm run test:e2e                  # 全部 suite
npm run test:e2e -- chain         # 仅主链
npm run test:e2e -- smoke         # 三端 smoke
npm run test:e2e -- session       # 课时全链
npm run test:e2e -- resume        # SSE 续传
E2E_SKIP=smoke,consultation npm run test:e2e   # 跳过部分
E2E_ONLY=chain,session npm run test:e2e        # 只跑指定
```

| E2E key | suite |
|---------|-------|
| `smoke` | 三端 async 冒烟 |
| `resume` | 跨 session 续传 |
| `coach` | 教练 Pi 短链 |
| `consultation` | 咨询 skill |
| `chain` | 计划/课时主链 |
| `session` | 课时 Pi 全链 |
