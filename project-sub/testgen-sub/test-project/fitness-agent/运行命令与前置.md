# fitness-agent · 运行命令与前置

---

## 站级自测（单测 / 站级集成）

```bash
cd fitness-agent/server
npm run test:stations
```

| 站 | 测试文件 | 前置 |
|----|----------|------|
| s01 | `frontend/tests/s01-frontend.test.mjs` | 可选 `cd frontend && npm install`（vue-tsc） |
| s02 | `s02-gate/tests/turn-submit-guard.test.ts` | Postgres + `DATABASE_URL` |
| s03 | `s03-queue/tests/turn-job-store.test.ts` | 同上 |
| s04 | `s04-pipeline/tests/s04-pipeline.test.ts` | 同上 + 种子数据（会员 10002/10003 等） |
| s05 | `s05-pi/tests/s05-pi.test.ts` | **无 DB、无 LLM** |
| s06 | `s06-stream/tests/turn-journey.test.ts` | Postgres |

### 环境变量

```bash
# server/.env 示例（本地 Docker）
DATABASE_URL=postgresql://...@localhost:5433/fitness
DEPLOY_MODE=local
```

本地一键起库：

```bash
cd fitness-agent/deploy && npm link
fitness local          # 或 fitness local:reset 重建种子
```

### 跳过部分 suite

```bash
# s04 内部 suite
S04_SKIP=bff,macro,session npm run test:stations

# E2E（非站级）
E2E_SKIP=smoke,consultation,resume npm run test:e2e
```

## 全栈 E2E（非单测）

```bash
cd fitness-agent/server
npm run test:e2e
```

**前置**：

- Docker 全栈 `:3001` 已启动
- `server/.env` 含 LLM Key（如 `DEEPSEEK_API_KEY`）

E2E suite 顺序见 `server/tests/README.md`：smoke → resume → coach → consultation → chain → session。
