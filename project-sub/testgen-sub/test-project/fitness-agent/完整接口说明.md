**图例**

| 标记 | 含义 |
|------|------|
| 方向 **正常** | HTTP 2xx/3xx；成功 JSON 通常**无**顶层 `code` |
| 方向 **异常** | HTTP 4xx/5xx 或 turn `status=failed` |
| Code **`-`** | 成功响应，无机器码 |
| **【待新增】** | 规划 code，尚未写入 `apiError.ts` |
| **【Legacy 无 code】** | 当前仅 `{ error }`，应对齐建议 code |
| **【AI 动态文本】** | `error` 来自 Pipeline/worker/LLM，非固定文案 |

**三端 async**：教练 `/api/chat/turns`、会员 `/api/member/chat/turns`、店长 `/api/admin/chat/turns` 结构相同；路径列用 `·` 合并。

**异常 envelope 公共字段**（下文简称「标准错误体」）：`error` 人类可读；`code` 机器码；可选 `retry_after_sec` 建议等待秒数；`retryable` poll 是否可重发；`circuit_breaker` DB 熔断；`queue_meta` 队列深度；`details` 结构化补充。

## ApiErrorCode 速查（与源码 JSDoc 同步）

| Code | 含义 |
|------|------|
| `HTTP_NOT_FOUND` | 路由未匹配 |
| `HTTP_VALIDATION` | 缺参/格式/业务前置校验 |
| `HTTP_INTERNAL` | 未捕获异常 / 500 兜底 |
| `AUTH_UNAUTHORIZED` | Internal Key 失败 |
| `TURN_*` | async 提交/轮询/取消（见 `apiError.ts` 注释） |
| `PLAN_*` | 宏观计划状态 gate |
| `SESSION_*` | 课时 CRUD |
| `FORM_*` | 计划表单 |
| `CHAT_SESSION_*` / `COACH_*` / `MEMBER_*` | 会话与身份 |
| `KB_*` | 知识库 internal |
| `RESOLVE_*` | 公开 ID |
| `JOURNEY_*` / `LOG_*` | 审计漫游 |
| `ADMIN_*` | 店长 internal 写 |
| `DELETE_CONFIRM_REQUIRED` | 删除须对话确认 |
| `SERVER_NOT_READY` | /ready 未就绪 |
