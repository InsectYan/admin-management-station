## 各文件建议覆盖用例

### `frontend/tests/agent-sse.test.mjs`

- `formatQueueMetaHint`：空 meta、仅 pending、含 retry_after_sec
- `readAgentSseStream`：mock ReadableStream，多 event 类型、buffer 拆包

### `s02-gate/tests/db-circuit.test.ts`

- `recordDbFailure` × N → `isDbCircuitOpen()` true
- `evaluateTurnSubmitGuard` → 503 + `circuit_breaker: true`
- 超时后半开 → `recordDbSuccess` 关闭

### `s02-gate/tests/turn-queue-policy.test.ts`

- mock `countQueueTurnJobs` 或插入 pending 行
- `pending >= maxPending` → action reject
- `pending >= warnPending` → action warn + estimated_wait_sec

### `s02-gate/tests/internal-api-key.test.ts`

- supertest + express 最小 app
- 有 Key：无 header → 401；正确 header → 200
- `/health` 不校验

### `s03-queue/tests/turn-job-lifecycle.test.ts`

- enqueue → claimNextTurnJob → processing
- completeTurnJob → completed + result_json
- failTurnJob → failed
- reclaimStaleTurnJobs：人工改 `updated_at` 超时

### `s03-queue/tests/turn-job-retry.test.ts`

- `isRetryableTurnError` 各 pattern
- `computeTurnRetryDelayMs(1..6)` 边界

### `s04-pipeline/tests/suites/outbox-contract.suite.ts`

- `validateCoachOutbox` 全 message_type 分支
- 合法/非法 payload 矩阵

### `s04-pipeline/tests/suites/portal-payload.suite.ts`

- `validatePortalOutbox("member", plan_form)` → 抛错
- `validatePortalOutbox("member", text)` → 通过

### `s05-pi/tests/outbox-draft-merge.test.ts`

- tmpdir 写 `draft_session_plan.md`
- `mergeDraftBodiesIntoOutbox` 优先 sidecar

### `s06-stream/tests/sse-frame.test.ts`

- 从 `agentSseStream` 抽帧函数（若有）或固定输入/output 快照
- heartbeat 间隔、completed 帧

## 接入 test:stations

现有 runner：`fitness-agent/server/scripts/run-station-tests.mjs`

- 自动递归 `server/src/stations/**/**/*.test.ts`
- s01 固定跑 `frontend/tests/s01-frontend.test.mjs`

**新增 `*.test.ts` 无需改 runner**；新增 suite 需在 `s04-pipeline.test.ts` 的 `SUITES` 数组注册（若独立 suite 文件）。

### s04 新 suite 注册示例

```typescript
const SUITES = [
  "bff-pipeline.suite.ts",
  "macro-plan-flow.suite.ts",
  "session-plan-flow.suite.ts",
  "outbox-contract.suite.ts",   // 新增
  "portal-payload.suite.ts",    // 新增
];
```

可选跳过：`S04_SKIP=bff,outbox npm run test:stations`
