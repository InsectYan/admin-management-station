# 运维项目配置 JSON 模板

列表页「导出模板」下载的就是本契约的空白文件。梳理项目时按字段填写，再通过「导入 JSON」生成运维项目；详情页编辑后可用「导出配置」回写完整 JSON。

- **schema**：固定 `ops-project/v1`
- **文件**：UTF-8 JSON，建议文件名 `ops-project-template.json`

## 根字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `schema` | 是 | `ops-project/v1` |
| `version` | 否 | 模板版本，当前 `1.0.0` |
| `_guide` | 否 | 字段中文说明，导入时忽略 |
| `name` | 是 | 项目名称 |
| `type` | 是 | `frontend` / `backend` / `fullstack` / `agent` |
| `description` | 否 | 职责与范围 |
| `repo_url` | 否 | Git 仓库地址 |
| `source_path` | 生成时必填 | 本地项目路径，Agent 按此扫描 |
| `status` | 否 | `draft` / `active` / `archived` |
| `directory_tree` | 否 | 目录树；节点可含 `flow_key` |
| `routes` | 否 | 前端路由；可含 `flow_key` 指向分流程 |
| `flows` | 否 | 必须含 `key=overview` 总览，外加各页面分流程 |
| `extra_json` | 否 | 反查表：`errors` / `risks` 等。风险仍须画在流程图上 |

## 目录树 `directory_tree[]`

```json
{
  "name": "src",
  "type": "dir",
  "description": "源码根目录",
  "children": [
    { "name": "main.js", "type": "file", "description": "入口", "children": [] }
  ]
}
```

`type` 仅允许 `dir` | `file`。文件节点 `children` 应为空。

## 路由 `routes[]`

```json
{
  "path": "/projects",
  "name": "ops-list",
  "component": "OpsProjectListPage",
  "meta": { "title": "项目列表", "auth": false },
  "children": []
}
```

仅 `frontend` / `fullstack` 需要填写。可嵌套 `children`。

## 功能流程 `flows[]`

每个流程对应详情页「功能流程」里的一个标签。节点与边用于 AntV X6 渲染。

### 节点 `nodes[]`

| 字段 | 说明 |
|------|------|
| `id` | 流程图内唯一 |
| `name` | 展示名 |
| `type` | `start` / `page` / `api` / `action` / `decision` / `end`（业务形态，不是风险分类） |
| `severity` | 可选 `warning` / `risk`。任意类型都能标；红/橙描边 |
| `description` | 该节点特点（入口、skill、围栏、回包） |
| `risk_note` | 标了 severity 时必填：为什么风险/警告，会导致什么问题 |
| `x` / `y` | 画布坐标 |

`severity=risk` 红色加粗描边：不可逆/清数据/伤病闸门。`severity=warning` 橙色加粗描边：鉴权或敏感入口。失败收口用业务类型（如 `action`）+ `severity=risk` + 边 `fail`，不要发明 `type=risk`。

### 边 `edges[]`

| 字段 | 说明 |
|------|------|
| `id` | 唯一 |
| `source` / `target` | 对应节点 `id` |
| `label` | 连线文字，如「成功」 |
| `type` | `next` / `success` / `fail` / `branch`（不同颜色） |

空白模板会预置「开始 → 功能入口 → 结束」三点一线，改名即可。

### `extra_json.risks`

排障反查表，**不能代替**图上的红/橙节点。键为稳定 code，值指向流程与节点：

```json
{
  "feat-cloud-ops-wipe": {
    "level": "risk",
    "when": "误 wipe 不可逆。phrase/env 能挡住一部分误操作，通过后无法从本接口恢复。",
    "flow_key": "feat-cloud-ops",
    "node_id": "wipe"
  }
}
```
