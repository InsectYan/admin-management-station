# 漫剧架构关系

浏览器只打漫剧 BFF `:5205`。出图仍先问预检 `:5204`，再提交本机 ComfyUI `:8188`。剪辑不走这两条。

```mermaid
flowchart LR
  Page["剪辑页 :5105"]
  Bff["cartoon BFF :5205"]
  Db[("cartoon_db")]
  Disk["data/outputs"]
  Ff["ffmpeg / ffprobe"]
  Pre["预检 :5204"]
  Comfy["ComfyUI :8188"]

  Page --> Bff
  Bff --> Db
  Bff --> Disk
  Bff --> Ff
  Bff --> Pre
  Bff --> Comfy
```

成片文件写在 `data/outputs/{projectId}/edit/{jobId}/episode.mp4`，并记入 `cartoon_outputs`。产物页用原来的 `GET /api/outputs/:id/file` 播放。
