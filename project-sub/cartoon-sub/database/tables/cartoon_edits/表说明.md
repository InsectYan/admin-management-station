# cartoon_edits

一个漫剧项目一条成片时间线。`project_id` 唯一。

| 列 | 说明 |
|----|------|
| project_id | 外键 `cartoon_projects`，删除项目时级联删除 |
| title | 默认「{项目名} 成片」 |
| width / height / fps | 导出画布。fps 默认 24 |
| duration_ms | 视频轨末尾，保存时重算 |
| status | `draft` 或 `exported`。保存改回 `draft`，导出成功记 `exported` |

关联接口：`GET/PUT /api/projects/:id/edit`，`POST /api/projects/:id/edit/seed`。无种子数据。
