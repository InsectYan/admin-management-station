# cartoon_edit_jobs

ffmpeg 拼接任务。不写入 `cartoon_tasks`，也不走预检和 ComfyUI。

| 列 | 说明 |
|----|------|
| edit_id | 外键 `cartoon_edits` |
| status | `queued`、`running`、`success`、`failed` |
| progress | 0–100 |
| error_message | 失败原因，页面原文展示 |
| output_id | 成功后指向 `cartoon_outputs` |
| args_snapshot | ffmpeg 参数数组，不含环境变量 |

进程内同时只跑一个任务。BFF 启动时，遗留的 `queued` / `running` 改为 `failed`，原因是「进程重启，导出中断」。

关联接口：`POST /api/projects/:id/edit/export`，`GET /api/edit-jobs/:id`。
