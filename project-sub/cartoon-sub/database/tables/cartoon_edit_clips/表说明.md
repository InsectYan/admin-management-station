# cartoon_edit_clips

轨道上的片段。时间单位是毫秒。

| 列 | 说明 |
|----|------|
| track_id | 外键 `cartoon_edit_tracks`，级联删除 |
| sort_order | 轨内顺序，从 0 起 |
| source_output_id | 视频片段绑定 `cartoon_outputs`。产物删除时置空，片段留在时间线上，预览显示素材缺失 |
| start_ms | 在成片上的起点。视频轨保存时按顺序重算 |
| duration_ms | 在成片上占据的长度，必须大于 0 |
| trim_in_ms | 源素材入点。视频轨要求入点加时长不超过源时长 |
| text | 仅字幕轨 |

无种子数据。
