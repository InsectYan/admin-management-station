# 08 总任务拆分

> 入口：列表「AI 开书」；创建页坞内「按缺口生成计划」  
> `feature_key`：`orchestrate`  
> Agent：[SKILL-任务拆分](./SKILL-任务拆分.md)  
> **本组件不写书名/人物正文**，只出计划；执行仍进 03～07 的会话，正文任务进详情单章（11）。

总览里的依赖链在这里落地：`fill_basic → world → factions → characters → outline → chapters → fill_chapter_body`（正文任务一次只写一章）。

---

## 1. 前端

**不要**再做一套和表单坞平行的「计划机器人」。复用 `AiFormDock`，差异：

- `fieldCatalog` 换成 **任务卡** 而不是表单 path：

| path | label |
|------|-------|
| `plan.basic` | 基础信息 |
| `plan.world` | 世界观 |
| `plan.factions` | 门派组织 |
| `plan.characters` | 人物 |
| `plan.outline` | 大纲 |
| `plan.content` | 章节 |
| `plan.bodies` | 正文（一次一章，进详情单章） |

- 输入：一句话意图（类型、读者、冲突）
- 助手结果：任务列表 + 每步 `reason` / `depends_on` / `status`
- 「应用到表单」在本组件改为 **「执行下一步」**：
  1. 若无 `novel_id`，先用 writer `fill_basic` 的预览让用户确认 → 现有 create API
  2. 打开对应步骤，把该步 `feature_key` 会话与 orchestrate 会话的 `trace` 写进 `bound_context`（父 plan id）
  3. `plan.bodies` 打开详情 `?tab=7` 第一个空章，而不是向导 step
  4. 在目标步坞自动发一条系统向 turns（可静默），或只跳转让用户在 03～07 / 11 点发送
- **「连续执行设定」**：`POST /api/ai/dispatch` 带 `scope: "settings"`，循环到 `t_content` 为止（不跑 `plan.bodies`）；每步把 `turn.patch` 写入向导表单并保存草稿，向导逐步切步展示；可取消。正文仍走详情队列。

列表：主按钮旁「AI 开书」打开 Dialog，上半意图，下半同一个坞。

未完成前置任务时，后续 Tab 禁用（与 Skill 的 `depends_on` 一致）。

---

## 2. 服务端

| 方法 | 路径 | 转发 |
|------|------|------|
| POST | `/api/ai/sessions/:id/turns` | `pipeline: ["orchestrator"]`，action `plan` / `replan` |
| POST | `/api/ai/dispatch` | body：`novel_id`、`plan_session_id`、`task_path`、可选 `scope: "settings"` → **再调** 目标 feature 的 turns（brainstorm+writer），不在 orchestrator 里套 invoke；`scope=settings` 找不到设定任务时返回 `{ done: true }`，不写正文 |

禁止 orchestrator Skill HTTP 调 writer。串行只发生在 `aiTurn` / `dispatch`。

`plan` 存进该会话最后一条 assistant 的 `patch_json`：`{ tasks: [...] }`。

---

## 3. Agent

仅 `novel-orchestrator-skill`。入参：intent、各步是否已有内容的布尔摘要、enum 短表。出参：`tasks[]`，见 Skill 文档。

---

## 4. 验收

- [ ] 计划里人物任务在世界观 `applied` 前不能 dispatch
- [ ] 目录未完成前 dispatch `plan.bodies` → 409 `DEPENDENCY_BLOCKED`
- [ ] 执行 `plan.bodies` 打开详情 tab=7 对应空章
- [ ] 执行基础信息后列表出现草稿，会话补上 `novel_id`
- [ ] orchestrator 响应不含大段设定正文（设定在 03～07，正文在 11）
- [ ] 「连续执行设定」跑到章节目录后停下，不自动写正文；取消后不再 dispatch
