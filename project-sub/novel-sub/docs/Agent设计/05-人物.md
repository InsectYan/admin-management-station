# 05 人物

> 页面：创建 step=3 `CharacterLibrary` + `CharacterCard` + `CharacterRelationGraph`  
> `feature_key`：`characters`  
> 第一道 **必须** 复用 [SKILL-头脑风暴](./SKILL-头脑风暴.md)（角色火花），再结构化

---

## 1. 前端

左侧角色列表、卡片、关系图保持手改。坞不内嵌第二套人物编辑器。

| path | label | kind | 默认露出 |
|------|-------|------|----------|
| `characters` | 角色库 | list | 是 |
| `character_edges` | 人物关系 | list | 是 |
| `characters[].personality` 等 | 当前选中卡字段 | text | 选中角色后露出 |

「当前角色」：坞增加只读提示「正在补全：{name}」，`target_fields` 用 `characters[{id}].personality` 这种 path。未选中角色时，本轮默认整库生成（`characters` + `edges`）。

应用策略：

- 整库：按 `name` 对齐合并，新角色 `createCharacter` 补 id；默认 **不删除** 已有角色
- 单卡：只 merge 该 id 的文本列
- 边：`source/target` 必须是已有或本轮 patch 内的角色 id/name（name 由前端解析成 id）

占位符：「按世界观给 1 主角 2 配角 1 反派，并标宿敌」。

---

## 2. 服务端

snapshot：`characters`、`character_edges`、world 摘要、basic 立意/类型。`pipeline`：`["brainstorm","writer"]`。

`role` 白名单 `main|support|villain`；边 `relation` 白名单 `ally|enemy|mentor|family|love`。BFF 在写 message 前过滤非法枚举。

---

## 3. Agent

| 顺序 | Skill | action | 说明 |
|------|-------|--------|------|
| 1 | brainstorm | `ideate` | 人设火花、关系张力、口头禅；**无 id、无边表** |
| 2 | writer | `fill_characters` | 角色数组 + edges |

单卡改写：writer `rewrite_field`，path 含角色 id。

头脑风暴在人物、书名、立意之间 **同一 Skill**，只是 `ideate` 的 `focus` 不同（`focus: "cast"`）。
