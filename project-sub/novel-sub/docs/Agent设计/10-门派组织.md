# 10 门派组织

> 页面：创建 step=3 `StepFactions`；详情 Tab 3 `DetailFactions`  
> `feature_key`：`factions`

组织实体（门派 / 家族 / 国家 / 势力），插在世界观与人物之间。不是章节场次。

## 1. 前端

`setting_json.factions[]`：`id` / `name` / `kind` / `alignment` / `description` / `rules` / `headquarters` / `member_ids`。

人物卡可选 `faction_id`。

## 2. Agent

writer `fill_factions`。`kind` 白名单 `sect|clan|nation|force|other`；`alignment` 白名单 `righteous|evil|neutral`。
