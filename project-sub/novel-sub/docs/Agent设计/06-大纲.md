# 06 大纲

> 页面：创建 step=4 `OutlineTree`  
> `feature_key`：`outline`

---

## 1. 前端

卷 / 章组 / 小节树保持手改与字数框。

| path | label | kind | 默认露出 |
|------|-------|------|----------|
| `outline.volumes` | 分卷结构 | tree | 是 |
| `word_targets` | 字数分配 | tree | 是（与结构同轮，可单独取消） |

应用默认：**空树则替换；已有卷则追加一卷** 或预览里选「整树替换」。禁止静默删用户卷。

占位符：「按长篇拆三卷，每卷两个章组」。

主题 Tab 不要拆到每一个小节 path（会上百）。粒度停在「分卷结构 / 字数」。小节标题在 `patch.volumes` 里一次带齐。

---

## 2. 服务端

snapshot：outline + `length_id` 对应 min/max 字数 + 人物名列表 + 立意。`pipeline`：brainstorm（情节点）→ writer `fill_outline`。无 `novel_id` 时 400 `NOVEL_REQUIRED`。

BFF 可做确定性校验：`countOutlineWords` 落在篇幅区间外时，在响应 `meta.warning` 提示，**不**自动改数字（让用户在坞里说「把字数压到 20 万」）。

---

## 3. Agent

| 顺序 | Skill | action |
|------|-------|--------|
| 1 | brainstorm | `ideate`，`focus: "plot"`：三幕/卷冲突，不写树 |
| 2 | writer | `fill_outline`：`volumes[].groups[].sections[]` + `word_target` |

结构字段名与 `createOutlineVolume` 一致。id 可由前端补。

---

## 4. 验收

- [ ] 空大纲应用后出现至少 1 卷 1 组 1 节
- [ ] 已有内容默认追加而非清空（或明确替换确认）
- [ ] 字数警告可见，仍允许用户自己保存
