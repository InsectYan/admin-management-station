# 04 世界观

> 页面：创建 step=2 `StepWorldSetting` + `WorldTimeline`  
> `feature_key`：`world`  
> 前置：有 `novel_id`（坞 `disabled` 直到步 1 保存）

---

## 1. 前端

折叠面板字段不改。向坞插入 **父级「世界观」+ 子级字段**，完整 JSON 见 [02 §1.4 示例](./02-表单AI坞.md)。勾父级 = 全部子集；只勾「时代背景」= 只生成 `era`。

`timeline` 应用策略：**合并追加**（按 `year+event` 去重）或用户在预览里选「替换全部」。默认追加，避免清掉手打节点。

占位符：「按立意补一套力量体系，并给 4 个历史节点」。

主题条：选中 `era` 时，对应 collapse 项自动展开（仅 UX，不改数据）。

---

## 2. 服务端

turns 的 `form_snapshot` 含本步 world，另附 `basic` 摘要（title、intent、genre 名称、themes）。`pipeline`：`brainstorm` → `writer`（`fill_world`）。无 `novel_id` 时 400 `NOVEL_REQUIRED`。

落库仍是用户保存后 `PUT /api/novels/:id/setting` 的 `world` 块。

---

## 3. Agent

| 顺序 | Skill | action |
|------|-------|--------|
| 1 | brainstorm | `ideate`（world 向：文明反差、禁忌、视觉锚点） |
| 2 | writer | `fill_world` |

`timeline[]` 项必须有 `year`、`event`；`id` 可由前端 `createTimelineNode` 补，Agent 可不传 id。

力量体系不得与步 1 类型明显矛盾（writer 用 basic 摘要约束；冲突写在 `reply` 里让用户改 Tab）。

---

## 4. 验收

- [ ] 无草稿 id 时坞禁用，文案「请先保存基础信息」
- [ ] 只勾选力量体系时，应用不改 timeline
- [ ] 时间轴默认追加，条数增加
