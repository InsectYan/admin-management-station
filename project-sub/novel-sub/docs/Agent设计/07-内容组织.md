# 07 章节目录（原「内容组织」）

> 页面：创建 step=6 `ChapterTagList`  
> `feature_key`：`content`  
> 职责：**只编排章节标题、顺序、关联大纲、正/反/中立场次**。门派/宗门等组织实体见 [10-门派组织](./10-门派组织.md)。正文见 [11-单章开发](./11-单章开发.md)。

---

## 1. 前端

章节标签、阵营、拖拽排序保持。AI **只出初始列表**，order 仍由前端重排。

| path | label | kind | 默认露出 |
|------|-------|------|----------|
| `chapters` | 章节列表 | list | 是 |
| `chapters.faction` | 阵营标注 | enum | 是（可与列表同轮） |
| `chapters.outline_ref` | 关联大纲 | text | 否 |

应用：默认按 `title` 合并追加；拖拽结果以用户为准，Agent 不要在下一轮把顺序改回去（snapshot 要带当前 `order`）。

占位符：「按大纲小节生成章节标题，并标正反派场次」。

向导第 6 步保存后，页脚主按钮旁有 **「开始写正文」**（至少一章才可点），进入详情 `?tab=7&chapter=<第一章>`。无章节时禁用。

---

## 2. 服务端

snapshot：`chapters` + outline 标题扁平列表。`pipeline` 默认 **仅 writer**（`fill_chapters`）。若用户要「更有戏的章名」再加 brainstorm。

`faction` 白名单 `hero|villain|neutral`。`outline_ref` 尽量匹配大纲节 title 或 id。

---

## 3. Agent

| Skill | action |
|-------|--------|
| writer | `fill_chapters` |
| brainstorm | 可选 `ideate` `focus: "chapter_titles"` |

patch：`{ chapters: [{ title, faction, outline_ref }] }`，不要 `order`。

---

## 4. 验收

- [ ] 应用后可继续拖拽，保存顺序稳定
- [ ] 只勾选阵营时不改标题
- [ ] 非法 faction 丢弃
- [ ] 至少一章时「开始写正文」可进详情 tab=7；无章节时禁用
