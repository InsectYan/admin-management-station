# 09 列表与详情

> 页面：`NovelListPage`、`NovelEditDialog`、`NovelDetailPage`  
> `feature_key`：`quick_edit`（弹窗快编）；详情补全 **不新建 feature**，跳向导复用 03～07

---

## 1. 前端

**列表**

- 工具栏「AI 开书」→ 08 Dialog（coverage 含门派与正文缺口）
- 有章节时表格/看板「去写正文」→ 详情 `?tab=7` 第一章
- 有空章时「续写」→ 详情 `?tab=7&queue=1`，弹出确认后串行写空章
- 列表进度 / 字数 / 章数为 BFF 按正文派生，快编完成度只读
- 空状态同一入口
- 筛选区、批量删除：**无 AI**

**编辑弹窗**

- 字段仍是现有表单
- 底部塞折叠坞，`feature_key=basic`（与向导基础信息 **共享会话组**，见 03），不要 `quick_edit` 再拆一组，除非产品要「快编草稿不影响向导会话」——默认共享
- 弹窗矮：坞默认一行，展开后出现主题 Tab

**详情**

- 设定 Tab 只读，不在 Tab 里塞输入框
- 另有详情专属「单章开发」（tab=7），创建/编辑不展示
- 「全书预览」（tab=8）按卷章 Markdown 只读，可导出 TXT / Markdown；改正文回单章
- 单章「会话」：开关只在正文栏；浏览只读历史，编辑才可聊/应用；应用后写入正文并重算字数
- 右上 **编辑设定** → `/novels/create?id=&step=&from=detail`，手改六模块，不展开坞
- 右上 **补全全部缺口** → 同上并带 `ai=plan`，打开计划坞
- 右上 **连续执行设定** → 同上并带 `ai=plan&autorun=settings`；有计划则自动 dispatch 到目录并逐步写入表单，无计划则停在计划坞
- 模块内 **用 AI 补全本模块** → 同上并带 `ai=1`，只展开本步坞、不自动发送（单章开发不展示）
- 右下只做详情模块翻页，不再跳向导
- 向导若 `from=detail`，返回详情（还原 tab / chapter），不要只回列表

封面：创建步 1 / 快编弹窗「AI 生成封面」，走侧栏多模态图片模型，不走文本 LLM。进度条：人工字段。
