## 3. 核心业务流程

```mermaid
%%{init: {'theme':'base', 'themeVariables': {'fontSize':'20px','actorFontSize':'20px'}}}%%
sequenceDiagram
    participant U as 用户
    participant L as NovelListPage
    participant B as BFF :5201
    participant D as novel_db

    U->>L: 打开 /novels
    L->>B: GET /api/novels
    B->>D: SELECT novels
    D-->>B: 列表
    B-->>L: JSON
    U->>L: 新建 / 编辑 / 删除
    L->>B: POST / PUT / DELETE /api/novels
    B->>D: 写入
```
