| 路由 name | 路径 | 组件 | 说明 |
|-----------|------|------|------|
| `novel-list` | `/novels` | `NovelListPage.vue` | 看板 + 表格 |

嵌入主应用时 basename 为 `/media/novel`（Qiankun props）。

## BFF API

```mermaid
flowchart TB
  FE[novel-sub frontend]
  BFF[Egg.js BFF :5201]
  DB[(PostgreSQL novel_db)]

  FE -->|"/api/novels"| BFF
  FE -->|"/api/novel-enums"| BFF
  FE -->|"/api/novels/:id/setting"| BFF
  BFF --> DB
```

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/novel-enums` | 类型树 / 题材 / 读者 / 篇幅 / 更新节奏 |
| GET | `/api/novels` | 列表（分页/筛选） |
| POST | `/api/novels` | 创建小说（步骤 1 草稿） |
| GET | `/api/novels/:id` | 详情 + `setting_json` |
| PUT | `/api/novels/:id` | 更新基础字段 |
| PUT | `/api/novels/:id/setting` | 合并写入 `setting_json` 分块 |
| DELETE | `/api/novels/:id` | 删除 |
| POST | `/api/novels/batch-delete` | 批量删除 |

### setting_json 结构

```json
{
  "world": { "era", "geography", "timeline": [] },
  "characters": [{ "id", "name", "role", "personality" }],
  "character_edges": [{ "id", "source", "target", "relation", "label" }],
  "outline": { "volumes": [{ "groups": [{ "sections": [] }] }] },
  "chapters": [{ "id", "title", "faction", "order" }]
}
```

## 数据库（枚举）

```mermaid
erDiagram
  genre_categories ||--o{ genre_subcategories : parent
  novels }o--o| genre_categories : type
  novels }o--o| genre_subcategories : subtype
  novels }o--o| length_categories : length
  novels }o--o| audience_categories : audience
  novels }o--o| update_paces : pace
  novels ||--o{ novel_themes : tagged
  theme_categories ||--o{ novel_themes : used
```

| 表 | 用途 |
|----|------|
| `genre_categories` | 小说类型一级分类 |
| `genre_subcategories` | 小说类型二级分类 |
| `theme_categories` | 题材标签（可多选，含热度） |
| `audience_categories` | 目标读者复合枚举 |
| `length_categories` | 篇幅与字数区间 |
| `update_paces` | 更新节奏 |
| `novel_themes` | 小说-题材多对多 |

`novels.genre` / `novel_type` / `target_audience` / `update_cadence` 仍作为名称冗余字段，便于列表筛选；真源为外键。

## Agent 调用关系（首批已落地：会话 + turns + 步 1 坞）

> 详细设计：[Agent设计/readme.md](./Agent设计/readme.md) · 产品入口：[docs-project/小说平台Agent.md](../../../docs-project/小说平台Agent.md)

前端 **不直连** Agent 平台。BFF 按会话 `pipeline` 串行调用 Skill；平台主 Agent 只负责 scheme 执行。明细：[Agent设计/00-组件拆分.md](./Agent设计/00-组件拆分.md)

```mermaid
flowchart TB
  UI["novel-sub 前端 :5101<br/>AiFormDock + 本次主题 Tab"]
  BFF["novel-sub BFF :5201<br/>agentProxy · aiTurn"]
  DB[(novel_db :5301)]
  AG["agent-management-master :4001<br/>主 Agent 统一流水线"]
  ORCH["novel-orchestrator-skill<br/>loop · plan"]
  BR["novel-brainstorm-skill<br/>react · ideate"]
  WR["novel-writer-skill<br/>react · fill_*"]

  UI -->|"/api/ai/sessions · turns"| BFF
  BFF -->|"现有 /api/novels"| DB
  BFF -->|"POST /api/skills/:name/invoke"| AG
  AG --> ORCH
  AG --> BR
  AG --> WR
  BFF -.->|"pipeline 串行 brainstorm→writer"| WR
```

| 角色 | 职责 |
|------|------|
| 平台主 Agent | 选 scheme、resolveLlm、跑 Executor |
| brainstorm | 书名/立意/人物等第一道火花，不写表单 JSON |
| writer | 收成对齐 schema 的 `patch` |
| orchestrator | 产出对齐五步的 `tasks[]`，不写正文 |
| BFF | 唯一网关；会话落库；注入枚举；用户确认后仍走现有 PUT |
